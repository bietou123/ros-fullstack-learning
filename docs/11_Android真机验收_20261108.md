## 限制与未覆盖项

- 该机 MIUI 拒绝 `adb shell input` 注入事件，报 `SecurityException: ... requires the INJECT_EVENTS permission`；`sendevent /dev/input/event5` 被 SELinux 拒绝，设备无 `su`。因此**物理触摸路径无法用 adb 自动化复现**。
- 上表中第 4–7 步的点击，是通过同一提交构建的 debug APK 的 WebView 调试通道（`adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>` + CDP `Runtime.evaluate` 触发 DOM 点击）完成的。Web 层代码与 release 相同，Android WebView 运行时相同，但 **release 构建（R8/压缩后）的真实触摸路径仍未验证**。
- 安装 release 包后仅验证了启动与首页渲染，未在 release 包上完成后续交互步骤。
- 验证结束后已卸载 debug 包并装回 `release/IndustryRoboticsLearning-0.1.23-arm64.apk`，设备上保留的是正式产物。
