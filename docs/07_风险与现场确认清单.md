# 07 · 风险、假设与「必须现场确认」清单

## 1. 风险台账

| # | 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|---|
| R1 | Electron / Capacitor 依赖下载失败（国内网络） | 中 | 阻塞 M0 | 配置 npm 镜像；Electron 单独镜像；失败如实上报，不伪造产物 |
| R2 | WSL 内构建 deb 时文件系统跨盘性能差 | 高 | 构建慢 | 构建目录放在 WSL 家目录，产物再复制回 D 盘 |
| R3 | Android 签名密钥丢失 | 中 | 无法升级覆盖安装 | keystore 生成后立即备份到 `D:\Private data\AI\Backups\`，仓库只存指针说明 |
| R4 | 课程内容含公司敏感信息 | 中 | 严重合规风险 | 公私内容包物理隔离；构建前扫描；私有包 `.gitignore` |
| R5 | 知识库本身有转述误差 | 高 | 教学错误 | 每个参数标注出处；冲突保留 ⚠；关键数值回原文核对 |
| R6 | 三端 WebView 渲染差异 | 中 | 一致性验收失败 | 只用成熟 CSS/JS 特性；抽检 10 节课做 DOM 文本哈希 |
| R7 | 仿真实验与真机差异大 | 高 | 学完上手仍有落差 | 每阶段末「现场还差什么」诚实清单；field 项强制标注 |
| R8 | 平板 ARM64 上 deb 安装失败 | 中 | 验收第 2 条不通过 | 用 arm64 构建；提前检查依赖；备选 AppImage |
| R9 | ROS1 Noetic 在 Ubuntu 24.04 上无官方 apt 源 | 高 | S1 实验阻塞 | 一律用 Docker 容器跑 ROS1，宿主不装 |
| R10 | 课程写作篇幅失控 | 中 | 交付延期 | 固定 9 段模板；每节 1200–2500 字；先骨架后填充 |

## 2. 假设

1. 学习者在 Windows 主力机上开发，Linux 通过 WSL2 或小米平板 Ubuntu 使用。
2. 平板（小米 Pad 6 Pro）最终能提供可用的 Ubuntu 环境；若失败，apk 端仍可只读学习 + SSH。
3. 网络可访问 npm 镜像与 GitHub API；若不可，开源发布延后并如实说明。
4. 公司知识库只在本地读取，不复制进仓库。
5. 用户接受「仿真为主、真机为辅」的教学边界。

## 4. 敏感信息红线

- 不写入：密码、Token、私钥、明文凭据、客户名、报价、设备 SN、真实 IP、内部域名、POPO 群号。
- 示例统一：`192.0.2.x`、`LD-E-EXAMPLE-0001`、`robot01`、`/opt/robot`。
- 构建前 `make scan` 必须 0 命中；命中即中止构建。
