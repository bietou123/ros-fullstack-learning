# 06 · 三端功能一致性矩阵与实验适配

## 1. 功能一致性矩阵

| 功能 | deb | exe | apk | 实现位置 |
|---|---|---|---|---|
| 课程目录 / 章节浏览 | 必须 | 必须 | 必须 | `apps/web` |
| Markdown、代码高亮、公式、图片 | 必须 | 必须 | 必须 | `apps/web` |
| 全文搜索、术语表、标签 | 必须 | 必须 | 必须 | `packages/core/search` |
| 视频 / 动图 / rosbag 说明 | 必须 | 必须 | 必须 | `apps/web` + 资源包 |
| 进度、笔记、错题本、间隔重复 | 必须 | 必须 | 必须 | `packages/core/store` |
| 阶段测验、能力雷达 | 必须 | 必须 | 必须 | `packages/core/quiz` |
| 私有内容包导入 / 导出 | 必须 | 必须 | 必须 | `packages/core/pack` |
| 内容包版本与哈希校验 | 必须 | 必须 | 必须 | `packages/core/pack` |
| 学习数据导出 / 导入同步 | 必须 | 必须 | 必须 | `packages/core/sync` |
| 实验运行 | 本地 Docker/ROS | WSL2 / 远程 SSH | 远程 SSH / 只读 | `packages/core/experiment` |
| 离线使用 | 必须 | 必须 | 必须 | 全部静态资源 |

> 唯一允许的平台差异是**实验后端**。界面、步骤、预期结果、检查项三端完全相同；后端不可用时统一显示「当前设备不能运行，可查看步骤 / 连接 Linux 后端」，禁止伪造运行结果。

## 2. ExperimentRunner 接口

```ts
export type BackendKind = 'local' | 'wsl2' | 'ssh' | 'read-only'

export interface ExperimentSpec {
  id: string
  ros: 'ros1' | 'ros2' | 'none'
  image?: string          // 容器镜像
  commands: string[]      // 顺序执行
  checks: string[]        // 检查脚本（退出码 0 为通过）
  expected?: string
  timeoutSec: number
  headless: boolean
}

export interface ExperimentResult {
  backend: BackendKind
  ok: boolean
  steps: { cmd: string; code: number; stdout: string; stderr: string; ms: number }[]
  checks: { name: string; ok: boolean; detail: string }[]
  reason?: 'no-backend' | 'timeout' | 'failed' | 'denied'
}

export interface ExperimentRunner {
  detectBackend(): Promise<BackendKind>
  run(spec: ExperimentSpec): Promise<ExperimentResult>
}
```

### 各端实现

| 端 | detectBackend | 执行方式 |
|---|---|---|
| deb | Docker/Podman 存在 → `local`；否则 `read-only` | `docker run --rm --network host -v ...`，容器内 bash |
| exe | 检测 WSL2（`wsl -l -v`）→ `wsl2`；配置了 SSH → `ssh` | `wsl.exe -d Ubuntu -- bash -lc "..."` 或 `ssh` |
| apk | 配置了 SSH 主机 → `ssh`；否则 `read-only` | Capacitor SSH 插件 / 原生 HTTP 桥接本地服务 |

### 无硬件实验底座

- `vcan0` 虚拟 CAN：`ip link add dev vcan0 type vcan && ip link set up vcan0`
- 虚拟串口：`socat -d -d pty,raw,echo=0 pty,raw,echo=0`
- 假 PLC / VCU：Python 脚本按 100 Hz 发送 `0x200+id` / `0x280+id` 假报文
- rosbag 回放：预置 `demo_bags/*.db3`，走 `ros2 bag play`

## 4. 数据表（IndexedDB）

| store | 主键 | 字段 |
|---|---|---|
| progress | lessonId | status, percent, lastAt, seconds |

| quiz_results | id | lessonId, answers[], correct, at |
