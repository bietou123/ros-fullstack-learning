# 05 · 里程碑计划（M0–M5）

## 总览

| 里程碑 | 交付物 | 验收断言 |
|---|---|---|
| M0 | 七项前置文档 + monorepo + 三端空壳包 | 同一 commit 产出 deb/exe/apk，三端能打开同一节课 |
| M1 | 内容引擎 + 内容包规范 + 阅读/搜索/进度/导入导出 | 内容包哈希一致；私有包可导入且不出现在公开产物 |
| M2 | S0–S2 共 23 节课 + 测验 + 实验 | 三端目录/正文/测验一致；S1 实验 deb 本地跑通 |
| M3 | S3–S6 共 27 节课 | 挖机 URDF、标定、安全实验全部有自动检查 |
| M4 | S7–S9 共 20 节课 | Nav2 跑通；Edge Bridge 配置实验；验收清单可用 |
| M5 | S10 毕业项目 + 全量打包 + 一致性验收 | 12 条验收标准逐条通过；GitHub 开源 |

## M0 · 骨架与冒烟（本次）

1. 资料盘点 / 能力矩阵 / 课程地图 / ADR / 里程碑 / 一致性矩阵 / 风险清单。
2. `pnpm` workspace：`packages/core`、`apps/web`、`apps/desktop`、`apps/mobile`。
3. 共享前端路由：首页 / 课程 / 课程详情 / 搜索 / 进度 / 设置。
4. 内置 1 个演示内容包（含 1 节课），三端加载同一份 `pack.json`。
5. `make package-deb / package-exe / package-apk` 三个入口。
6. 产物：`dist/ros-learning_<ver>_amd64.deb`、`dist/ros-learning Setup <ver>.exe`、`dist/ros-learning-<ver>.apk`。

**M0 完成定义**：三端安装包装出来并能显示同一节课正文，且设置页显示同一内容哈希。

## M1 · 内容引擎

- 内容包 `manifest.json`：`id / version / hash / min_app_version / visibility / built_at / lessons[]`。
- 构建脚本 `scripts/build-pack.mjs`：扫描 `content/packs/public` → 生成 `pack.json` + SHA256。
- 引擎：Markdown + Shiki + KaTeX 渲染、FlexSearch/MiniSearch 全文索引、进度、笔记、书签、测验、错题本、间隔重复（SM-2 简化版）。
- 存储：IndexedDB（`idb`），统一 schema：`progress / notes / quiz_results / bookmarks / settings / content_version`。
- 导入导出：JSON 全量导出/导入合并；私有包 zip 导入（JSZip）。
- 敏感扫描：`scripts/scan-secrets.mjs`，构建前阻断。

## M2–M4 · 课程

每节课固定 9 段结构，附带：
- `meta.yaml`：`id/title/duration/stage/type/tags/sources/experiment/quiz[]`
- `experiment.yaml`：`ros/version/image/commands/checks/expected/timeout/headless`
- 自动检查脚本（Python 或 bash），全部可 headless。

## M5 · 毕业项目与发布

- S10 六个任务 + 仿真挖机全链路仓库模板。
- 三端全量打包、SHA256、签到产物。
- 12 条验收逐项出报告。
- 开源：公开引擎 + 公共内容包；公司内容包永不发布。

**当前状态（2026-11-03）**：课程 76/76、S10 六节完成；v0.1.4 已发布，exe/deb(amd64+arm64)/apk 内嵌同一内容哈希 `150e1d22…7cb7`。Windows 安装与 WSL2 实验通道实测通过；Linux 无 Docker 时正确降级只读；错题本、阶段测验与构建 commit 展示已补齐，并在桌面断网冒烟与 Android 模拟器完成回归。逐条结论见 `docs/10_M5验收报告.md`；真机与干净环境项仍未闭环，不作「全部通过」宣称。

## 节奏假设

- 不按天排期，按依赖推进：M0 → M1（引擎）→ M2 → M3 → M4 → M5。
- 每个里程碑结束必须跑 `make verify`：类型检查 + 单元测试 + 三端一致性抽检。
