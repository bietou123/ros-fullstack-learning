## 4. 课程完成判定

一节课程「学会」需同时满足：

1. 正文阅读完成（进度 ≥ 90%）。
2. 实验检查脚本通过（或明确标注 field，只能现场完成）。
3. 3 道复盘题全部答对一次以上。
4. 能在 7 天后间隔重复中再次答对（间隔重复队列）。

阶段「毕业」需满足：该阶段所有 teach 课程的 1–4 完成 + 产出物提交 + 阶段能力检查通过。
