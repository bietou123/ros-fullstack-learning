## 私有内容包导入回归（2026-11-02）

在 Android 34 x86_64 模拟器上用合成的 `rl.private.demo`（76 节 / 11 阶段 / `bc0bd180…03fd`，无公司数据）回归验收第 6 条，发现**私有包导入在所有平台都必然失败**：

- `savePrivatePack` 把内容包对象直接 `put` 进以 `id` 为 keyPath 的 IndexedDB 存储，但内容包顶层没有 `id`，真实 id 在 `manifest.id`；浏览器抛 `DataError: Evaluating the object store's key path did not yield a value`，设置页显示「导入失败」。
- 之前只验证了哈希算法一致和导入 UI 存在，没有跑通实际导入链路，v0.1.0 / v0.1.1 均受影响。

修复：`packages/core/src/store.ts` 新增 `privatePackRecord()`，以 `manifest.id` 生成存储键后再写入；新增单测「私有包存储键取自 manifest.id」，单测 12/12 通过。

## 已知环境坑（可复现）

1. **Windows 下 Gradle Wrapper 相对路径失败**：`execSync('gradlew.bat', {cwd})` 在 PowerShell/`cmd` 组合下报「不是内部或外部命令」。改为调用绝对路径 `"<androidDir>/gradlew.bat"`。
2. **electron-builder 解压 `winCodeSign`**：归档内 macOS 符号链接需要管理员权限。处理：手动解压时排除 `darwin/`，放到 `%LOCALAPPDATA%\electron-builder\Cache\winCodeSign\winCodeSign-2.6.0\`。
3. **GitHub 直连下载超时**：使用 `ELECTRON_MIRROR` 与 `ELECTRON_BUILDER_BINARIES_MIRROR` 指向 npmmirror。
4. **Android `local.properties` 路径**：必须写正斜杠（`D:/Private data/AI/Tools/android-sdk`），反斜杠会被 Java properties 吞掉。
5. **WSL 复用 Windows `node_modules`**：会缺 `@rollup/rollup-linux-*` 等 Linux 原生包。处理：rsync 源码到 `~/rl-build`（排除 `node_modules/dist/release/apps/*/web`）后重新 `pnpm install --frozen-lockfile`。
6. **WSL 内 corepack**：需固定 `packageManager` 并 `corepack enable --install-directory ~/.local/bin pnpm`。
7. **内容包哈希算法漂移**：构建脚本、`verify.mjs` 与 `@rl/core` 曾各自实现 manifest 规范化，导致 `min_app_version` / `minAppVersion` 别名不一致，设置页会把合法内容包判为校验失败。现已统一为固定字段表，并新增单测「构建产物必须通过核心库校验」。
8. **打包脚本误报/误拷历史产物**：`package:exe` / `package:deb` 曾把 `dist/` 里所有历史版本一起复制并打印 RELEASE，v0.1.1 发布时因此把 0.1.0 exe 也拷进 `release/`。现已按当前 `package.json` 版本过滤，deb 要求 amd64/arm64 两个都存在，缺失即失败。
