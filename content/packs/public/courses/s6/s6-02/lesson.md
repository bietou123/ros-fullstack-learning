# S6-02 · 限幅与斜坡

> 验证状态：✅ 本课限幅与斜坡命令已在本机 Linux 实测；⚠ 未在实机上验证加速度/冲击效果，参数为**教学示例**。

## 1. 现场类比

手柄一推到底，整机猛地一顿，液压系统「咚」一声，斗杆上的工具都跟着抖。

这不是操作手的问题，是**指令从 0 直接跳到最大值**。限幅管「最多多快」，斜坡管「多快能变多快」，两者缺一不可。

## 2. 核心概念

### 2.1 两类限制

| 类型 | 限制什么 | 公式 | 防什么 |
|---|---|---|---|
| 限幅 clamp / saturation | 幅值 | `out = min(max(x, lo), hi)` | 超速、超行程 |
| 斜坡 rate limiter | 变化率 | `out += clamp(target−out, −r·dt, +r·dt)` | 冲击、抖动、过流 |

**限幅≠斜坡。** 只限幅，目标从 0 变到上限时仍是阶跃；只加斜坡，不设上限，慢慢也能爬到危险值。

### 2.2 斜率要按「每秒」写

```
每周期最大增量 = rate_per_sec × dt
```

如果代码里写死「每周期 0.1」，控制周期从 10 ms 变成 20 ms，实际变化率就减半，**行为随负载漂移**。

### 2.3 上升和下降可以不对称

- 加速太快 → 冲击、过流；
- 减速太快 → 机械冲击、液压冲击；
- 常用：加速慢、减速可以稍快（但不能无限快）。

### 2.4 限幅的顺序

```
目标 → 幅值限幅 → 斜坡 → 再限幅 → 输出
```

最后再限一次，防止斜坡在边界附近把值带出范围。若控制器里有积分项，还要做 **anti-windup**，否则积分会一直累积，松开后仍「冲过头」。

### 2.5 与安全层的关系

限幅/斜坡属于「让动作好看、少冲击」，**不能替代**急停、看门狗、硬件限位。软件限幅失效时，必须有独立的硬件保护兜底。

## 3. 可复制命令 / 代码

```bash
# 幅值限幅
python3 -c "lim=lambda x,lo,hi:max(lo,min(hi,x)); print([lim(v,-1.0,1.0) for v in (-2,-0.5,0,0.5,2)])"

# 斜坡限速：目标 1.0，每周期最多 0.1
python3 -c "out=0.0; tgt=1.0; rate=0.1; seq=[]; [(out:=out+max(-rate,min(rate,tgt-out)), seq.append(round(out,3))) for _ in range(8)]; print(seq)"
```

预期：限幅结果 `[-1, -0.5, 0, 0.5, 1]`；斜坡序列 `[0.1, 0.2, …, 0.8]`，**不会一步跳到 1.0**。

## 4. 动手实验

**目标（35 分钟）**：实现一个限幅器 + 斜坡，并测出它的响应特性。

1. 给一个关节设定速度上限（示例 0.5 rad/s）和加速度上限（示例 1.0 rad/s²）；
2. 用控制周期 10 ms 计算每周期最大增量；
3. 输入阶跃目标，记录多少周期到达目标；
4. 输入正弦目标，观察跟随误差与相位滞后；
5. 把上升/下降斜率改成不对称，比较差异；
6. 写结论：当前参数下，阶跃到达时间是多少？是否会产生明显冲击？

**通过判据**：阶跃响应单调、无超调；到达时间与 `目标/斜率` 的理论值一致（误差 < 1 个周期）。

## 5. 自动检查

```bash
python3 -c "out=0.0; tgt=1.0; rate=0.1; seq=[]; [(out:=out+max(-rate,min(rate,tgt-out)), seq.append(out)) for _ in range(20)]; assert all(b>=a for a,b in zip(seq,seq[1:])) and abs(seq[-1]-1.0)<1e-9; print('RAMP_OK')"
```

预期输出 `RAMP_OK`：单调上升并最终到达目标。

## 6. 常见故障

| 症状 | 可能原因 | 排查 |
|---|---|---|
| 动作起停有明显冲击 | 没有斜坡、斜率过大 | 降加速度上限 |
| 响应越来越慢 | 斜率写成每周期固定值，实际周期变长 | 改为 rate×dt |
| 到达后仍在漂 | 积分饱和、没有 anti-windup | 加积分限幅/条件积分 |
| 限幅后仍超速 | 限幅只加在命令端，反馈未检查 | 反馈端也做限位 |
| 松手后冲过头 | 斜坡目标未归零 / 队列积压 | 目标归零，清空队列 |
| 不同负载下表现不同 | 参数与周期/液压特性绑定 | 参数化，重新标定 |
| 边界附近抖动 | 斜坡与限幅互相顶 | 最后统一限幅，加小滞环 |
