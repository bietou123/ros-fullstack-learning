# S6-01 · 遥操映射：手柄 → 关节速度

> 验证状态：✅ 本课死区与映射计算命令已在本机 Linux 实测；⚠ 未接真实手柄与整机验证手感，硬件相关参数为**教学示例**。

## 1. 现场类比

操作手说「这台机器的斗杆太贼」——手柄只推了一点点，斗杆却窜得很快；换一台又「太肉」，推到底才慢慢动。

机器没坏，是**映射关系**不一样。遥操映射表就是操作手和机器之间的「手感合同」，写清楚了，换人不换手感。

## 2. 核心概念

### 2.1 输入是什么

| 输入 | 范围 | 说明 |
|---|---|---|
| 摇杆轴 | −1.0 ~ +1.0 | 已归一化；不同手柄轴编号不同 |
| 扳机 | 0 ~ 1 | 常做「使能/比例」 |
| 按钮 | 0 / 1 | 离散事件，不适合直接做连续速度 |
| 安全使能 | 0 / 1 | 未按下时**必须**输出零速度 |

### 2.2 映射链路的五步

```
原始轴值 → 死区 → 归一化 → 符号 → 增益 → 限幅 → 平滑 → 关节速度
```

| 步骤 | 作用 | 典型值（示例） |
|---|---|---|
| 死区 | 过滤摇杆回中误差，避免松手漂移 | 0.05 ~ 0.15 |
| 归一化 | 死区外重新映射到 0~1，避免「跳过一段」 | `(x−dz)/(1−dz)` |
| 符号 | 手柄方向 → 关节正方向 | +1 / −1 |
| 增益 | 满杆对应最大速度 | 见下 |
| 限幅 | 不超过结构/安全上限 | 关节速度上限 |
| 平滑 | 抑制突变，见 S6-02 斜坡 | 每周期最大增量 |

### 2.3 增益怎么定

```
满杆速度 = 操作手期望的最大速度
增益 = 满杆速度 / 1.0
```

增益不是拍脑袋：先问「这个关节最多允许多快」，再问「操作手希望多快」，取小值。

### 2.4 映射表至少包含

| 列 | 例子 |
|---|---|
| 输入源 | 手柄左摇杆 Y 轴 |
| 关节 | 动臂 |
| 符号 | +1（推前 = 抬臂） |
| 死区 | 0.10 |
| 满杆速度 | 0.5 rad/s |
| 单位 | rad/s |
| 超时归零 | 100 ms |
| 备注 | 与 S6-05 看门狗联动 |

**这张表就是产出物。** 没有表，参数只存在某个人的记忆里。

## 3. 可复制命令 / 代码

```bash
# 死区 + 归一化：输入 0.55，死区 0.10，增益 2.0 rad/s
python3 -c "dz=0.1; x=0.55; y=0.0 if abs(x)<=dz else (1 if x>0 else -1)*(abs(x)-dz)/(1-dz); print('stick=%.2f out=%.3f vel=%.3f'%(x,y,2.0*y))"

# 整条输入输出曲线
python3 -c "dz=0.1; f=lambda x:0.0 if abs(x)<=dz else (1 if x>0 else -1)*(abs(x)-dz)/(1-dz); print([(x,round(f(x),3)) for x in (-1.0,-0.5,-0.1,0.0,0.1,0.5,1.0)])"
```

预期：`0.55 → 0.500 → 1.000 rad/s`；曲线在 ±0.1 内为 0，两端达到 ±1。

## 4. 动手实验

**目标（35 分钟）**：写出一张完整映射表，并用代码验证。

1. 选 3 个关节（或 2 个关节 + 1 个回转），确定每个关节的安全最大速度；
2. 为每个关节指定输入轴、符号、死区、满杆速度；
3. 用本课代码画出输入输出曲线，确认死区外连续、满杆达标；
4. 测试极值：−1、0、+1，以及「快速来回」时的输出；
5. 规定松手与超时行为：输出归零，多久归零；
6. 写结论：这张表换给另一个操作手，能否复现同样手感？

**通过判据**：映射表每列都有值，且代码验证满杆速度等于表中所写。

## 5. 自动检查

```bash
python3 -c "dz=0.1; f=lambda x:0.0 if abs(x)<=dz else (1 if x>0 else -1)*(abs(x)-dz)/(1-dz); assert f(0.05)==0 and abs(f(0.55)-0.5)<1e-9 and f(1.0)==1.0; print('MAPPING_OK')"
```

预期输出 `MAPPING_OK`。

## 6. 常见故障

| 症状 | 可能原因 | 排查 |
|---|---|---|
| 推杆没反应 | 死区过大、未按使能、轴编号错 | 打印原始轴值 |
| 方向相反 | 符号写反 | 单轴小幅度测试 |
| 一推就窜 | 增益过大、无斜坡 | 降增益，见 S6-02 |
| 松手还在动 | 未归零、无超时保护 | 加超时归零，见 S6-05 |
| 小幅推杆抖动 | 死区太小、摇杆噪声 | 调死区或加滤波 |
| 组合动作不协调 | 映射耦合/增益不匹配 | 两轴同时测试，统一量纲 |
| 两台设备手感不同 | 参数未统一或未标定 | 用同一张表和同一套标定流程 |
