# S7-01 · SLAM 概念与建图

> 验证状态：✅ 本课栅格概率更新与里程漂移计算命令已在本机 Linux 实测；⚠ 未用真实激光数据跑 SLAM，建图流程与工具为标准用法但**本机未实测**。

## 1. 现场类比

第一次进一个陌生厂房，边走边在纸上画：墙在哪、门在哪、自己走到哪了。

**画图和认路是同时进行的**——这就是 SLAM（Simultaneous Localization and Mapping）。难点在于：图错了会带偏位置，位置错了又会把图拼歪，两者互相影响。

## 2. 核心概念

### 2.1 SLAM 的两条腿

| 部分 | 作用 | 典型方法 |
|---|---|---|
| 前端 front-end | 相邻帧配准，估计位姿增量 | 扫描匹配 scan matching、ICP |
| 后端 back-end | 全局优化，消除累积误差 | 位姿图 pose graph、因子图 factor graph |
| 回环 loop closure | 认出「来过这里」，把回路闭合 | 描述子匹配 + 全局优化 |

**没有回环，误差只会越积越大。** 回环是建图精度的关键，不是锦上添花。

### 2.2 地图表示

| 表示 | 说明 | 适用 |
|---|---|---|
| 栅格地图 occupancy grid | 每格 0–100 表示占据概率 | 2D 导航、Nav2 |
| 点云地图 | 保留三维点 | 3D 定位、可视化 |
| 特征地图 | 只存角点/线面 | 轻量定位 |
| 拓扑地图 | 节点+边 | 路径规划上层 |

常见做法：**栅格 + 概率**。每个格子维护「占据概率」，新观测不断更新。

### 2.3 概率怎么更新

用对数几率 log-odds，避免概率连乘：

```
L ← L + 观测增量
p = 1 / (1 + e^(−L))
```

命中 +0.9、空闲 −0.7 只是示例，具体值要按传感器调。

### 2.4 建图流程

1. 确认传感器外参与时间同步（S4-07 / S5-04）；
2. 低速、平稳地覆盖整个区域；
3. **闭合回路**：回到起点或重访已知区域；
4. 保存地图，检查墙面是否重影、闭环是否对齐；
5. 标注禁行区、危险区（人工后处理）；
6. 版本化管理：环境变了必须重测。

### 2.5 地图质量判据

| 指标 | 合格表现 |
|---|---|
| 墙面一致性 | 同一面墙只有一层，不重影 |
| 闭环误差 | 回到起点，地图能对齐 |
| 覆盖完整度 | 作业区域无空洞 |
| 动态物体 | 行人/车辆不残留在地图里 |
| 可复现性 | 同环境两次建图差别很小 |

## 3. 可复制命令 / 代码

```bash
# 栅格 log-odds 更新：3 次命中 + 2 次空闲
python3 -c "import math; L=0.0; [(L:=L+d) for d in (0.9,0.9,0.9,-0.7,-0.7)]; print('L=%.2f p=%.3f'%(L,1/(1+math.exp(-L))))"

# 里程计 1% 漂移，走 100 m 后误差约多少
python3 -c "print('drift_m=%.1f'%(100*0.01))"
```

预期：`L=1.30 p=0.786`（仍判为占据）；直行 100 m 累积约 1 m 漂移——**不回环就会一直涨**。

## 4. 动手实验

**目标（35 分钟）**：走完一次小场景建图，并给出质量结论。

1. 选一个 ≤50 m² 的封闭区域（仿真或实机低速）；
2. 检查传感器外参、时间戳、TF 是否正常；
3. 低速绕行一圈，**回到起点附近完成闭环**；
4. 保存地图，检查墙面重影与闭环对齐；
5. 在图上标出 3 个关键点位（门、柱、作业区），记录坐标；
6. 写结论：覆盖是否完整？闭环误差多大？哪些区域需要补扫？

**通过判据**：地图闭合、墙面无明显重影、作业区无空洞，且能说出至少一处需要改进的地方。

## 5. 自动检查

```bash
python3 -c "import math; L=0.0; [(L:=L+d) for d in (0.9,0.9,0.9,-0.7,-0.7)]; p=1/(1+math.exp(-L)); assert 0.7<p<0.9; print('SLAM_GRID_OK')"
```

预期输出 `SLAM_GRID_OK`。

## 6. 常见故障

| 症状 | 可能原因 | 排查 |
|---|---|---|
| 墙面双层/重影 | 外参错、时间不同步、速度太快 | 查 TF 与时间戳，降速重扫 |
| 回到起点对不上 | 没有回环或回环失败 | 增加重访，检查描述子参数 |
| 地图越走越歪 | 前端匹配失败、特征太少 | 增加环境特征，检查激光视场 |
| 行人被画进地图 | 动态物体未过滤 | 后处理清除，建图时清场 |
| 地图有空洞 | 扫描覆盖不足、盲区 | 补扫，调整安装高度/角度 |
| 两次建图差别大 | 环境变化、参数不稳定 | 固定参数，记录环境状态 |
| 定位在地图里跳 | 地图质量差/初始位姿错 | 先修图，再重定位 |
