# S7-05 · 路径跟踪与调参

> 验证状态：✅ 本课曲率与限速计算命令已在本机 Linux 实测；✅ 2026-11-06 在 `ros:humble-nav2` 合成差速底盘上完成一次真实闭环跟踪（`/cmd_vel` → 里程计/激光 → AMCL → 规划/控制 → 到达），并实测了终点容差与速度指令；⚠ 未在实机上做 lookahead/速度对比调参，调参结论仍为通用思路。

## 1. 现场类比

同样一条线，有的机器走得又稳又准，有的左右画龙、弯道切角。

路径没问题，规划也没问题——是**跟踪控制器**的「看多远、转多快、跑多快」没配好。

## 2. 核心概念

### 2.1 跟踪在做什么

给定一条路径，控制器不断输出速度指令，让机器人「贴着路径走」。核心是两件事：

1. **横向误差**要小；
2. **航向误差**要收敛，不能来回摆。

### 2.2 前视距离（lookahead）

Pure Pursuit 类控制器会选路径上一个「前视点」，朝它开：

```
曲率 κ = 2y / L²
```

- `y`：前视点在车体坐标下的横向偏移；
- `L`：前视距离。

| lookahead | 效果 |
|---|---|
| 太小 | 追得紧，但容易振荡、画龙 |
| 太大 | 平稳，但切弯、滞后大 |
| 随速度自适应 | 低速小、高速大，通常最优 |

### 2.3 速度与曲率

转弯时离心加速度 `a = v²·κ`，所以：

```
v_max = sqrt(a_lat_max / κ)
```

先定允许的横向加速度，再按曲率限速。**直道快、弯道慢**，比全程一个速度更稳。

### 2.4 常见控制器

| 控制器 | 特点 | 适用 |
|---|---|---|
| DWB | 采样多组速度，打分选优 | 通用、避障强 |
| RPP (Regulated Pure Pursuit) | 前视 + 曲率限速 | 平滑路径 |
| MPPI | 采样优化，参数多 | 复杂动态环境 |

### 2.5 调参顺序（由粗到细）

1. 先确认定位、TF、代价地图没问题（否则调参是白费）；
2. 定最大速度与横向加速度；
3. 调 lookahead（先大后小，找到不振荡的最小值）；
4. 调横向/航向增益；
5. 最后调恢复行为与平滑；
6. 每次只改一个参数，记录前后指标。

### 2.6 评价指标

| 指标 | 说明 |
|---|---|
| 横向误差 RMS | 离路径多远 |
| 最大横向误差 | 最危险时刻 |
| 航向误差 | 车头偏多少 |
| 到达时间 | 效率 |
| 速度/加速度平滑度 | 舒适与机械冲击 |

## 3. 可复制命令 / 代码

```bash
# 前视点横向偏移 0.5 m、前视距离 2.0 m 时的曲率与转弯半径
python3 -c "y=0.5; L=2.0; k=2*y/L/L; print('curvature=%.3f radius=%.3f'%(k,1/k))"

# 曲率 0.25、允许横向加速度 1.0 m/s² 时的限速
python3 -c "import math; k=0.25; alat=1.0; print('v_max=%.2f'%math.sqrt(alat/k))"
```

预期：`curvature=0.250 radius=4.000`；`v_max=2.00` m/s。曲率越大，允许速度越低。

## 4. 动手实验

**目标（40 分钟）**：跑一条含直道和弯道的路径，完成一次参数调整并记录指标。

1. 记录基线：当前 lookahead、速度、横向误差 RMS、最大误差；
2. 只改 lookahead（先增大 50%），重跑，记录指标；
3. 再减小 50%，重跑，观察是否振荡；
4. 用本课公式计算弯道限速，与当前设置对比；
5. 选一组「误差小且不振荡」的参数；
6. 写结论：lookahead 与速度各自对指标的影响是什么？

**通过判据**：三次以上对比数据、参数只改一个、最终横向误差 RMS 下降且无明显振荡。

## 5. 自动检查

```bash
python3 -c "import math; k=2*0.5/2.0/2.0; v=math.sqrt(1.0/k); assert abs(k-0.25)<1e-9 and abs(v-2.0)<1e-9; print('PURSUIT_OK')"
```

预期输出 `PURSUIT_OK`。

**可复现的闭环跟踪实测**：沿用 S7-03 的完整栈与 `nav2_bringup` 默认 DWB 参数（`max_vel_x: 0.26`、`min_vel_x: 0.0`、`xy_goal_tolerance: 0.25`、`yaw_goal_tolerance: 0.25`），从 `(1.2, 0.0, 90°)` 导航到 `(1.0, -1.0)`。合成底盘以 20 Hz 积分 `/cmd_vel` 并回发 `/odom` 与 `/scan`，Nav2 控制指令实测序列（2 s 采样）：先原地转向 `(0.00, 0.16)`，再加速转向 `(0.25, 1.00)`，随后 `(0.26, 0.26)` 贴路径，接近终点转为 `(0.00, 0.68)`，最后 `(0.00, 0.16)` 对正航向。动作结果：8.71 s 完成，最终车体位姿 `(0.923, -0.767)`，距目标 0.221 m，小于 `xy_goal_tolerance` 0.25 m，`number_of_recoveries: 0`。

两个实测结论：
- 导航停在「进入容差」而不是几何目标点：本例停在离目标 0.221 m 处并判成功。要更贴点，先缩小 `xy_goal_tolerance` 与 `yaw_goal_tolerance`，同时给终点加减速/停稳判据，别只改一个。
- 2 s 一次的位姿打印会漏掉控制细节（控制环约 20 Hz）。要看完整速度曲线，用 `ros2 topic echo /cmd_vel` 或 rosbag 记录，再算横向误差与加速度；单次成功到达只能证明链路通，不能证明「走得好」。

## 6. 常见故障

| 症状 | 可能原因 | 排查 |
|---|---|---|
| 左右画龙 | lookahead 太小、增益过高 | 增大 lookahead，降增益 |
| 弯道切角 | lookahead 太大、速度过高 | 减小 lookahead，按曲率限速 |
| 直道也偏 | 定位漂移、外参误差 | 先查定位与标定 |
| 到达目标附近打转 | 到达判据太严/控制器振荡 | 放宽容差，加终点减速 |
| 遇到障碍急停 | 局部代价地图膨胀过大 | 调代价地图，见 S7-04 |
| 速度忽快忽慢 | 限速逻辑与平滑冲突 | 统一由 velocity_smoother 输出 |
| 同一参数换场地就变差 | 地面摩擦/负载变化 | 分场景参数集，现场复调 |
