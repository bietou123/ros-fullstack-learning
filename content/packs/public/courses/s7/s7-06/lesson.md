# S7-06 · 工程机械场景差异

> 验证状态：⚠ 本课为阅读课，无实验命令。结论来自通用工程实践与现场踩坑整理，**不包含任何具体客户或项目数据**；实际方案须以现场评估为准。

## 1. 现场类比

把仓库里跑得很稳的导航方案搬到露天料场，第一天就出问题：地面松软、GPS 时有时无、堆料每天都在变、旁边还有人走动。

**室内导航的经验不是不能用，是不能直接照搬。** 先弄清哪里不一样，再决定改什么。

## 2. 核心概念

### 2.1 环境对比

| 维度 | 室内移动机器人 | 工程机械现场 |
|---|---|---|
| 地面 | 平整、摩擦稳定 | 松软、泥泞、坡道、碎石 |
| 结构 | 墙、门、固定通道 | 无固定通道，堆料经常变化 |
| 定位 | 2D 激光 + 先验地图 | GNSS/RTK + IMU + 激光融合，常无可靠先验图 |
| 动态障碍 | 行人、叉车 | 人员、卡车、其他工程机械 |
| 通信 | Wi-Fi 覆盖稳定 | 无线覆盖不均，远控延迟波动 |
| 安全距离 | 按室内速度设计 | 质量大、惯性大，制动距离长 |
| 供电 | 市电/电池稳定 | 振动、粉尘、温度变化大 |

### 2.2 感知差异

- **粉尘/雨雾**：激光点云出现噪点、有效距离下降；
- **振动**：IMU 噪声增大、安装松动会导致外参漂移；
- **强光**：相机过曝，视觉特征丢失；
- **反光/镜面**：激光测距出现虚假点；
- **GNSS 多路径**：料堆、车身反射导致定位跳变。

### 2.3 定位与地图

- 工地往往**没有稳定先验地图**，或地图每天都在变；
- 依赖 GNSS 时，要设计「失锁」后的降级策略（IMU 推算、激光匹配）；
- 建图更多用于局部作业区，而不是整场；
- 地图更新频率要匹配现场变化速度。

### 2.4 规划与控制

| 差异 | 影响 |
|---|---|
| 非完整约束/铰接转向 | 不能直接套用差速模型 |
| 低速大惯量 | 制动距离长，必须提前减速 |
| 液压执行器 | 有死区、滞后、流量限制，控制参数与电机不同 |
| 地形起伏 | 平面 2D 代价地图不够，需要坡度/可通行性 |
| 作业区域限制 | 电子围栏、禁行区比路径优化更重要 |

### 2.5 安全与通信

- 现场有人，**任何时候都要假设有人会进入作业区**；
- 远控链路必须能检测延迟/断线，并进入安全状态（见 S6-05）；
- 急停必须是独立硬线回路（见 S6-04）；
- 作业前清场、设置警戒、明确指挥信号，软件不能替代流程。

### 2.6 哪些能迁移，哪些不能

| 能迁移 | 不能直接迁移 |
|---|---|
| ROS2 通信与节点架构 | 室内 2D 地图与固定路径 |
| 状态机、看门狗、限幅框架 | 室内速度/加速度参数 |
| 标定方法论 | 差速运动模型 |
| 日志与故障注入方法 | 理想 Wi-Fi 假设 |
| 行为树编排思路 | 小惯性制动距离 |

## 3. 阅读与核对清单

阅读本课后，用自己的项目逐项核对：

```text
□ 作业区地面是否平整？坡度上限多少？
□ 定位是否有 GNSS？失锁后如何降级？
□ 地图是否每天变化？由谁更新？
□ 现场有哪些动态障碍？如何检测？
□ 制动距离是否按最大质量与速度核算？
□ 无线覆盖是否有盲区？断线后行为是什么？
□ 急停是否独立于软件？
□ 作业区是否有人员进入风险？如何隔离？
```

**任何一项答不上来，都是现场风险点。**

## 4. 动手实验（阅读任务）

**目标（30 分钟）**：产出你所在场景的「差异清单」。

1. 对照 2.1 的表格，逐项填写你现场的实际情况；
2. 标出与室内方案**不一致**的项；
3. 对每个不一致项，写出「直接照搬会怎样」和「需要改什么」；
4. 按风险排序，选出前 3 项；
5. 写结论：哪一项是当前最大风险？下一步验证动作是什么？

**通过判据**：至少 6 项有具体描述，风险前 3 项有明确的验证动作。

## 5. 自检问题

1. 你的定位方案在 GNSS 失锁 30 秒后还能工作吗？
2. 你的制动距离是否按满载、最大速度计算过？
3. 现场地图变化后，多久能更新并通知所有设备？
4. 远控断线后，设备是停车还是保持最后指令？
5. 作业区有人进入时，系统靠什么发现？

五题中有一题答不上来，就先别谈「自动化」。

## 6. 常见故障 / 常见误判

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 晴天正常、雨天定位飘 | 激光噪点、地面反光 | 加滤波，降低雨天速度 |
| 每次开工位置都偏 | GNSS 多路径、初始位姿没确认 | 固定初始点，检查卫星状态 |
| 堆料变化后路径失效 | 地图未更新 | 建局部动态层，定期重扫 |
| 制动距离比预期长 | 按空载估算、地面湿滑 | 按最坏工况重算安全距离 |
| 无线盲区突然断控 | 覆盖评估不足 | 补基站，设计断线安全行为 |
| 参数在实验室好用、现场不行 | 负载/地面/温度差异 | 现场复调，分场景参数集 |
