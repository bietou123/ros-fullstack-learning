# S3-05 · 挖掘机四连杆几何建模

> 验证状态：✅ 2026-11-04 本机 Linux 实测余弦定理求缸长与反解关节角（Python 标准库）。文中尺寸全部为**教学示例值**，不代表任何实车参数；实车几何必须现场实测并单独管理，不进入公开内容包。

## 1. 现场类比

挖机的动臂、斗杆、铲斗不是三个独立的转动关节——铲斗是由**液压缸推动一套连杆**带动的。你在界面上看到的「铲斗角度」，是连杆机构算出来的，不是直接从铰点测出来的。

如果把连杆当成直连关节建模，模型在中间行程会有几度到十几度的偏差。**看起来能跑，标定时怎么都对不上。**

## 2. 核心概念

### 2.1 三个液压缸三段链路

| 动作 | 驱动方式 | 中间机构 |
|---|---|---|
| 动臂升降 | 两个动臂缸并联 | 近似直推（缸体-活塞-动臂） |
| 斗杆收放 | 单个斗杆缸 | 近似直推 |
| 铲斗翻转 | 单个铲斗缸 | **四连杆**（缸→摇杆→连杆→铲斗） |

只有铲斗是真正的闭环四连杆，其余可以按「缸长 ↔ 关节角」一维映射处理。

### 2.2 缸长与关节角：余弦定理

设铰点 A（缸体端）、B（活塞端），两铰点到转动中心 O 的距离为 `a`、`b`，夹角为 θ：

```
缸长 l = sqrt(a² + b² - 2ab·cosθ)
θ = arccos((a² + b² - l²) / (2ab))
```

```python
import math
def cyl_len(a, b, theta_rad):
    return math.sqrt(a*a + b*b - 2*a*b*math.cos(theta_rad))

def joint_angle(a, b, l):
    c = (a*a + b*b - l*l) / (2*a*b)
    c = max(-1.0, min(1.0, c))          # 数值保护，避免 acos 域外
    return math.acos(c)
```

**示例**：a=1.0 m、b=1.2 m、θ=60° → l≈1.11 m（仅为演示公式，非实车值）。

### 2.3 四连杆为什么不能直接写进 URDF

URDF 是**树**：每个 link 只有一个父 joint。四连杆里「摇杆—连杆—铲斗」构成闭合回路，树结构无法表示。

两种工程做法：

| 做法 | 实现 | 优点 | 缺点 |
|---|---|---|---|
| 等效关节法 | 用连杆几何解出铲斗角，只发布 `bucket_joint` | 简单、稳定、实时性好 | 中间连杆不显示 |
| 闭环仿真 | Gazebo / MuJoCo 的约束或闭环求解 | 物理真实 | 求解慢、参数难标定 |

**远控监视与运动学解算用等效关节法**；物理仿真才需要闭环。

### 2.4 建模前的现场测量清单

- 每个铰点的**相对位置**（不是绝对坐标）；
- 缸体/活塞铰点位置；
- 关节的**机械限位**（不是软件限位）；
- 各连杆的**实际长度**（含销轴中心距）。

**少测一个铰点，整个模型的误差就会传递到铲斗齿尖。**

## 3. 可复制命令 / 代码

```bash
# 先纯 Python 验算，不依赖 ROS
python3 - <<'PY'
import math
a, b = 1.0, 1.2
for deg in (0, 30, 60, 90):
    l = math.sqrt(a*a + b*b - 2*a*b*math.cos(math.radians(deg)))
    back = math.degrees(math.acos((a*a + b*b - l*l)/(2*a*b)))
    print(f"{deg:3d}° -> l={l:.4f} -> {back:.3f}°")
PY
```

预期：每一行输出的反算角度与输入一致（误差 < 1e-9），说明公式与实现自洽。

## 4. 动手实验

**目标（45 分钟）**：建立自己的机构几何表并验算。

1. 画一张铰点示意图（纸笔即可），标出 O、A、B 与连杆节点；
2. 填入你自己的测量值（**本文件不提供任何实车数据**）；
3. 用上面的 Python 片段验证「角度 → 缸长 → 角度」闭环；
4. 计算整段行程内关节角与缸长的映射曲线；
5. 标出哪一段接近奇异（缸长变化对角度不敏感/过于敏感）。

**通过判据**：反算误差 < 1e-6，并能指出行程中哪一段传动比最差。

## 6. 常见故障

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 按图纸标称值建模 | 与实车偏差数度 | 现场实测销轴中心距 |
| 忽略缸的安装偏置 | 中间行程偏差最大 | 用三维铰点，不用一维近似 |
| 用软件限位代替机械限位 | 模型能到但车到不了 | 以机械限位为准 |
| 四连杆硬写进 URDF | 模型断裂/不联动 | 等效关节法 |
| 角度单位混用 | 首末行程差一倍 | 全程弧度，显示层转度 |
