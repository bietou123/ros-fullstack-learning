# S10-04 · 标定与 TF 集成

> 验证状态：✅ 本机 Linux 实测了 2D 坐标链组合与手算对照；⚠ 课程中的连杆尺寸、角度均为**教学示例值，非实车参数**；实车标定数据不进公开内容包。

## 1. 现场类比

相机看到前方有障碍，机械臂却往反方向躲。算法没错、标定也做过——错在坐标链：`camera_link` 到 `base_link` 的外参方向反了。

**坐标变换错一位，所有上层算法都跟着错，而且看起来「很合理」。**

## 2. 核心概念

### 2.1 TF 树

```
base_link
  ├→ boom_link → stick_link → bucket_link → tip_link
  └→ lidar_link / camera_link（静态外参）
```

- 每个坐标系只有一个父节点；
- 树中任意两点可通过组合变换得到；
- **frame_id 拼写必须完全一致**，大小写与下划线都算。

### 2.2 静态与动态

| 类型 | 内容 | 发布方式 |
|---|---|---|
| 静态 | 传感器安装外参、连杆固定偏置 | static transform |
| 动态 | 关节角、旋转铰接 | 按状态实时发布 |
| 时间戳 | 动态变换必须带时间 | 与传感器时间对齐（S4-07） |

**静态外参用动态方式发布、或动态变换不带时间戳，都会造成「偶尔对、偶尔错」。**

### 2.3 变换的组合

```
T_base_tip = T_base_boom · T_boom_stick · T_stick_tip
```

矩阵乘法**不可交换**：先旋转再平移 ≠ 先平移再旋转。写代码时顺序错一位，结果差很远。

### 2.4 标定结果落在哪里

| 项 | 要求 |
|---|---|
| 存储位置 | 参数文件 / 参数服务器，路径固定 |
| 版本号 | 与配置部署表一致（S9-06） |
| 单位 | 米 / 弧度，写清楚 |
| 坐标系约定 | 机体 FLU、相机 optical，转换明确（S5-07） |
| 有效期 | 安装变动、碰撞后必须重标 |

### 2.5 三种校验方法

1. **手算对照**：取一个简单角度，手算末端坐标，与程序结果比；
2. **闭环验证**：正向变换后再做逆变换，应回到原点；
3. **点对齐**：用已知点（标定板、触地点）比对预测位置与实测位置。

**三种都做一遍，比只看「图上看起来对」可靠得多。**

### 2.6 常见错误

- 漏乘一段变换；
- 旋转与平移顺序反；
- 角度制与弧度制混用；
- `frame_id` 拼写不一致；
- 动态变换时间戳早于传感器数据；
- 把相机光学坐标系当机体坐标系直接用。

### 2.7 集成顺序

先静态外参 → 再关节链 → 再传感器 → 最后端到端点对齐。**从简单到复杂，每步都能单独验证。**

## 3. 可复制命令 / 代码

```bash
# 2D 坐标链：base → boom(0.5, 30°) → stick(2.0, 20°) → tip(1.0)
python3 -c "import math; a1=math.radians(30); a2=math.radians(20); x=0.5+2*math.cos(a1)+1*math.cos(a1+a2); y=2*math.sin(a1)+1*math.sin(a1+a2); print('tip=(%.3f,%.3f)'%(x,y))"
```

预期：

```
tip=(2.875,1.766)
```

含义：三段连杆依次累加，角度也累加。**这里的 0.5 / 2.0 / 1.0 m 是教学示例，不是实车尺寸。**

## 4. 动手实验

**目标（45 分钟）**：搭建一条可验证的坐标链。

1. 定义 base、两段连杆与末端共 4 个坐标系；
2. 用代码组合变换，算出末端位置；
3. 手算同一组角度，与程序结果对照；
4. 实现逆变换，验证闭环回到原点；
5. 故意把旋转/平移顺序调反，观察结果差异并记录；
6. 写结论：哪种错误最难发现？如何用校验提前发现？

**通过判据**：程序与手算一致；闭环误差在阈值内；能说明顺序错误的后果。

## 5. 自动检查

```bash
python3 -c "import math; a1=math.radians(30); a2=math.radians(20); x=0.5+2*math.cos(a1)+1*math.cos(a1+a2); y=2*math.sin(a1)+1*math.sin(a1+a2); assert abs(x-2.875)<0.001 and abs(y-1.766)<0.001; print('TF_OK')"
```

预期输出 `TF_OK`。

## 6. 常见故障

| 症状 | 可能原因 | 排查 |
|---|---|---|
| 传感器目标位置整体偏移 | 外参平移错 | 手算对照，检查单位 |
| 目标方向反了 | 旋转方向/坐标系约定错 | 核对 FLU/optical 转换 |
| 偶发坐标跳变 | 动态 TF 时间戳不一致 | 对齐传感器时间 |
| 某段坐标完全对不上 | 漏乘一段变换 | 打印每一级中间结果 |
| 换安装位置后全错 | 外参未更新 | 重标并更新版本 |
| 正变换对、逆变换错 | 旋转矩阵未转置/未求逆 | 闭环验证 |
| TF 树报多父节点 | 同一 frame 被两处发布 | 查发布源，保证唯一父节点 |
