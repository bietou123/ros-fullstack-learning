# S5-03 · Camera 驱动与图像管线

> 验证状态：✅ 本课延迟统计命令已在本机 Linux 实测；⚠ 未连接真实相机验证驱动、编码与时延，硬件相关结论为标准工程实践但**本机未实测**。

## 1. 现场类比

操作员屏幕上看到画面「还行」，但远程控制时总感觉慢半拍——人眼能忍 100 ms，闭环控制不能。

**画面流畅 ≠ 延迟低。** 深缓冲能让画面不卡，代价是把「现在」换成了「半秒前」。远控场景里，这个代价是撞墙。

## 2. 核心概念

### 2.1 图像链路的每一级都会加延迟

```
传感器曝光 → 驱动取帧 → 编码/压缩 → 网络/中间件 → 解码 → 算法 → 显示
    ~10ms      ~5ms        ~10–50ms      ~1–50ms    ~5–20ms   ...
```

每一级都有缓冲。**总延迟 = 各级处理时间 + 各级排队时间**，排队时间往往才是大头。

### 2.2 关键参数

| 参数 | 影响 | 现场建议 |
|---|---|---|
| 分辨率 | 带宽、处理时间 | 够用即可，别盲目 4K |
| 帧率 | 流畅度、带宽 | 控制用 30 fps 通常足够 |
| 曝光时间 | 运动模糊、低光亮度 | 运动中优先短曝光 |
| 增益 | 亮度、噪声 | 优先补光，不靠拉增益 |
| 自动曝光 | 亮度自适应 | 会引起帧率/延迟波动，控制场景建议锁定 |
| 快门类型 | 卷帘会撕裂，全局不会 | 运动场景优先全局快门 |
| 编码 | 带宽 vs 延迟 | 低延迟优先，别用大 GOP |

### 2.3 时间戳：三种时刻不要混

| 时刻 | 含义 | 用途 |
|---|---|---|
| 曝光/采集时刻 | 光子打到传感器 | **算法唯一应使用的时间** |
| 驱动取帧时刻 | 驱动收到完整帧 | 近似值，受传输影响 |
| 发布/解码时刻 | 上层拿到图像 | 只能算「处理延迟」，不能当采样时间 |

### 2.4 延迟怎么测

1. **时间码法**：屏幕上显示高精度时钟，相机拍它，对比画面时间与本地时间；
2. **LED 法**：LED 亮灭与图像中亮灭对比，适合测整条链路；
3. **软件打戳法**：在驱动入口和算法出口各打一次时间戳，得到的是软件链路延迟（不含曝光与传输）；
4. **统计口径**：看 P50 和 P99，不要只看平均值。

## 3. 可复制命令 / 代码

```bash
# 合成 1000 帧端到端延迟，输出 P50 / P99 / 最大值
python3 -c "import random; random.seed(3); lat=[max(0,random.gauss(25,8)) for _ in range(1000)]; s=sorted(lat); print('p50=%.1f p99=%.1f max=%.1f'%(s[500],s[990],s[-1]))"

# 缓冲深度对延迟的影响：30 fps，单帧 33.3 ms
python3 -c "fps=30; base=20.0; print('depth1=%.1fms depth5=%.1fms'%(base+1000/fps, base+5*1000/fps))"
```

预期：`p50≈24.8 p99≈44.2 max≈50.2`；深度 1 → 53.3 ms，深度 5 → 186.7 ms。**多出来的不是处理慢，是排队。**

## 4. 动手实验

**目标（30 分钟）**：为你的图像链路做一份延迟预算，并找出最大的一块。

1. 列出链路每一级，估算或实测其耗时；
2. 记录当前分辨率、帧率、曝光、编码方式；
3. 用软件打戳法测驱动入口 → 算法出口的 P50 / P99；
4. 把缓冲深度从默认值改成 1，重测一次，对比差异；
5. 判断瓶颈：编码？网络？还是队列？
6. 写结论：当前链路能否满足控制需求？需要改哪一级？

**通过判据**：能给出各级延迟预算表、P50/P99 数值，以及至少一条可执行的优化项。

## 5. 自动检查

## 6. 常见故障

| 症状 | 可能原因 | 排查 |
|---|---|---|
| 画面花屏 / 卡顿 | 带宽不足、线材差、编码参数过高 | 降分辨率/码率，换线 |
| 操作延迟明显但画面流畅 | 缓冲过深、GOP 过大 | 减缓冲、用低延迟编码 |
| 帧率忽高忽低 | 自动曝光、CPU 抢占 | 锁曝光，查 CPU 占用 |
| 时间戳一成不变 | 复用了旧帧 / 驱动 bug | 对比帧序号与时间戳 |
| 颜色偏、发紫 | 白平衡、IR-cut、补光 | 固定白平衡，检查滤光片 |
| 运动画面撕裂 | 卷帘快门 + 快速运动 | 换全局快门或降速 |
| 夜间噪点多 | 增益过高、补光不足 | 补光，限制增益 |
