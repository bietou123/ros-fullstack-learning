# S5-05 · 挖掘机连杆 + IMU 外参标定

> 验证状态：✅ 本课连杆与外参计算命令已在本机 Linux 实测；⚠ 未做实车标定。**本课所有尺寸、角度均为合成教学示例，非任何实车参数**；实车连杆尺寸与标定结果属于现场资料，不进入公开内容包。

## 1. 现场类比

同一台挖机，斗齿实际在 A 点，屏幕却显示在 A 点偏左 20 cm。操作手凭经验修正——换个操作手，又得重新适应。

更麻烦的是：三台同型号设备，偏差方向和大小都不一样。因为**每台的连杆实际尺寸、传感器安装角度都有差异**。出厂参数只能当起点，不能当结果。

## 2. 核心概念

### 2.1 从液压缸到斗齿

```
动臂 boom ──▶ 斗杆 stick ──▶ 铲斗 bucket ──▶ 斗齿 tip
   ↑ 关节1         ↑ 关节2         ↑ 关节3
```

末端位置由**各段长度 + 各关节角**决定。角度可以来自：

| 方案 | 原理 | 优点 | 缺点 |
|---|---|---|---|
| 缸行程换算 | 液压缸位移 → 几何关系 → 关节角 | 直接、抗振动 | 需标定缸与连杆几何 |
| 角度传感器 | 直接测关节角 | 直观 | 安装与零位需标定 |
| 连杆 IMU | 每个连杆装 IMU 测姿态 | 不改结构 | 每个 IMU 都有安装外参，需逐台标 |

**IMU 方案的代价**：每增加一个 IMU，就多一个待标定的旋转矩阵。

### 2.2 待标定量

| 符号 | 含义 | 说明 |
|---|---|---|
| L1 / L2 / L3 | 各段等效连杆长度 | 铰点到铰点的距离，非结构外形长度 |
| q1 / q2 / q3 | 各关节角 | 含零位偏置 |
| R_i | 第 i 个 IMU 到所在连杆的安装旋转 | 3 个自由度（通常忽略安装平移） |
| t_i | IMU 安装位置 | 若关心杆件角速度，需要；只求姿态可忽略 |

简化模型（平面两连杆，**教学示例值**）：

```
x = L1·cos(q1) + L2·cos(q1+q2)
y = L1·sin(q1) + L2·sin(q1+q2)
```

真实设备是三段以上、且存在平面外分量，但**误差传播规律相同**。

### 2.3 误差会被放大

末端误差 ≈ 各段长度误差 + 各关节角误差 × 对应力臂。

- 角度误差 1°、力臂 3 m → 末端误差约 5.2 cm；
- 三段串联，每段都贡献，误差叠加；
- 臂展越大，同样的角度误差造成的位置误差越大。

**所以标定的重点往往不是「算法多先进」，而是「角度和长度标得准不准」。**

### 2.4 标定方法

1. **已知末端点**：把斗齿放到若干个已知位置（触地法，见 S5-06），记录各关节角/IMU 姿态；
2. **构建残差**：预测末端位置 vs 已知位置；
3. **优化求解**：同时优化 L、零位角、R_i，使总残差最小；
4. **交叉验证**：留出部分点位，验证外推误差；
5. **重复性检查**：同一位置多次测量，看结果是否稳定。

约束优化时要加物理约束：长度为正、角度范围有限、R_i 接近安装设计值。**不加约束容易解出物理上不可能的参数。**

## 3. 可复制命令 / 代码

```bash
# 两连杆正运动学（L1=3.0 m, L2=2.0 m 为教学示例值）
python3 -c "import math; L1,L2=3.0,2.0; q1,q2=math.radians(30),math.radians(60); x=L1*math.cos(q1)+L2*math.cos(q1+q2); y=L1*math.sin(q1)+L2*math.sin(q1+q2); print('tip=(%.3f,%.3f)'%(x,y))"

# 1° 角度误差在 3 m 力臂上的末端误差
python3 -c "import math; L=3.0; print('1deg_tip_err_cm=%.1f'%(L*math.radians(1)*100))"

# IMU 安装旋转：传感器系重力 (0,9.81,0) 转到本体系（绕 z 转 90°）
python3 -c "import math; g=9.81; a=math.radians(90); c,s=math.cos(a),math.sin(a); sx,sy,sz=0.0,g,0.0; bx,by,bz=c*sx-s*sy, s*sx+c*sy, sz; print('sensor=(%.2f,%.2f,%.2f) body=(%.2f,%.2f,%.2f) norm=%.2f'%(sx,sy,sz,bx,by,bz,math.sqrt(bx*bx+by*by+bz*bz)))"
```

预期：`tip=(2.598,3.500)`；`1deg_tip_err_cm=5.2`；旋转后模长仍为 `9.81`（旋转不改变重力大小）。

## 4. 动手实验

**目标（45 分钟）**：用合成数据走一遍连杆 + IMU 外参标定的仿真流程。

1. 设定一组「真值」参数：L1、L2、零位角、IMU 安装角（自定，**不要用实车数据**）；
2. 生成 6 个不同姿态下的末端位置（正运动学）；
3. 给真值参数加小扰动，作为「待标定初值」；
4. 计算初值下的末端误差，记录 RMS；
5. 手动或写简单搜索/最小二乘，调整参数使 RMS 下降；
6. 用未参与拟合的 2 个姿态做验证，比较训练误差与验证误差；
7. 写结论：哪些参数最敏感？哪些参数之间存在耦合、难以单独辨识？

**通过判据**：能给出真值参数、初值误差、优化后误差、验证误差四组数据，并说明至少一组耦合关系。

> 仿真归仿真。实车标定要按现场 SOP 执行，**结果数据留在现场资料中**。

## 5. 自动检查

```bash
python3 -c "import math; L1,L2=3.0,2.0; q1,q2=math.radians(30),math.radians(60); x=L1*math.cos(q1)+L2*math.cos(q1+q2); y=L1*math.sin(q1)+L2*math.sin(q1+q2); g=9.81; a=math.radians(90); c,s=math.cos(a),math.sin(a); bx,by=c*0.0-s*g, s*0.0+c*g; assert abs(x-2.598)<0.01 and abs(y-3.5)<0.01 and abs(math.hypot(bx,by)-g)<1e-9; print('LINKAGE_OK')"
```

预期输出 `LINKAGE_OK`。

## 6. 常见故障

| 症状 | 可能原因 | 排查 |
|---|---|---|
| 整体偏移，各姿态偏差方向一致 | 零位角或连杆长度系统性偏差 | 重标零位与长度 |
| 不同姿态偏差方向不同 | 角度刻度/IMU 安装角误差 | 逐关节检查安装外参 |
| 动作过程中位置跳变 | IMU 松动、线缆接触不良、丢包 | 检查安装与通信 |
| 标定后一段时间又偏 | 温度漂移、结构变形 | 记录温度，考虑在线补偿 |
| 只有大臂展时误差大 | 长度误差被放大 | 重点标定长段，检查柔性 |
| 左右两侧表现不一致 | 两台设备参数不同 | 逐台标定，不套用参数 |
| 优化不收敛/参数离谱 | 缺物理约束、初值差、外点多 | 加约束、换初值、剔外点 |
