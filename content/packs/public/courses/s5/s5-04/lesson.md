# S5-04 · 外参标定原理与工具

> 验证状态：✅ 本课刚体变换恢复命令已在本机 Linux 实测（二维教学示例）；✅ 2026-11-06 在 `ros:noetic-perception` 容器（OpenCV 4.2）用合成数据实测三维工具链：`solvePnPRansac` 恢复外参（旋转误差 < 0.001°、平移误差 < 1e-6 m、重投影 RMS 4e-6 px），`ppf_match_3d_ICP` 配准（残差 1.15e-4、角度/平移误差 < 0.001）；⚠ 未用真实标定板与传感器做外参标定，硬件部分**未实测**。

## 1. 现场类比

雷达说障碍在正前方 3 米，相机说在左前方 2.8 米。两个都没坏——它们只是「站在不同的地方看」。

外参标定就是回答一个问题：**传感器 A 的坐标系，怎么变换到传感器 B 或本体坐标系？** 标错了，融合结果会把两个正确观测拼成一个错误世界。

## 2. 核心概念

### 2.1 内参 vs 外参

| | 内参 intrinsic | 外参 extrinsic |
|---|---|---|
| 描述 | 传感器自身成像/测距特性 | 传感器相对本体/其他传感器的位姿 |
| 例子 | 焦距、主点、畸变、激光角度偏差 | 平移 t、旋转 R |
| 变了怎么办 | 基本不变，出厂/大修后重标 | 拆装、碰撞、震动后必须重标 |
| 常见错误 | 用错分辨率下的内参 | 拿旧外参继续用 |

### 2.2 手眼标定 AX = XB

```
A：机器人两次位姿之间的变化（从关节/编码器得到）
B：传感器两次观测之间的变化（从标定板/点云得到）
X：待求的传感器到末端的固定变换（外参）
```

| 形式 | 传感器装在哪 | 标定物 |
|---|---|---|
| Eye-in-hand | 装在末端，随臂运动 | 固定标定板 |
| Eye-to-hand | 固定在工作空间 | 随臂运动的标定板 |

**核心思想**：不管怎么动，X 都不变。用多组 (A, B) 联立求解 X。

### 2.3 标定数据要「足够激励」

只在一个位置采 100 组数据，不如在 10 个不同姿态各采 10 组。

- 至少三个**非共面**的旋转姿态；
- 覆盖实际工作空间，而不是只覆盖装配台；
- 标定物要在视场中心与边缘都出现；
- 记录时间戳，运动中的点对要同步。

### 2.4 结果怎么评价

| 指标 | 含义 | 判据示例（教学值） |
|---|---|---|
| RMS 残差 | 所有点对误差的均方根 | 小于传感器本身噪声的 2 倍 |
| 最大残差 | 最坏点 | 不应出现孤立大值 |
| 交叉验证 | 留出姿态的误差 | 与训练集同量级 |
| 重复性 | 重复标定多次的差异 | 旋转 < 0.1°、平移 < 1 mm（示例） |

**残差小不等于标定对**——如果标定物只在中心、姿态太单一，残差可以很小但外推很差。

> 实车标定数据、真实连杆尺寸属于现场资料，**不进公开内容包**。本课所有数值均为教学示例。

## 3. 可复制命令 / 代码

```bash
# 旋转 90° 后反变换，验证往返一致
python3 -c "import math; a=math.radians(90); c,s=math.cos(a),math.sin(a); x,y=1.0,2.0; q=(c*x-s*y,s*x+c*y); q2=(c*q[0]+s*q[1],-s*q[0]+c*q[1]); print('p=(%.3f,%.3f) q=(%.3f,%.3f) q2=(%.3f,%.3f)'%(x,y,q[0],q[1],q2[0],q2[1]))"

# 从 6 组点对恢复刚体变换（二维 Kabsch 最小二乘）
python3 -c "import math; P=[(0,0),(1,0),(0,1),(2,1),(1,2),(-1,1)]; a=math.radians(30); c,s=math.cos(a),math.sin(a); Q=[(c*x-s*y+1, s*x+c*y+2) for x,y in P]; px=sum(p[0] for p in P)/6; py=sum(p[1] for p in P)/6; qx=sum(q[0] for q in Q)/6; qy=sum(q[1] for q in Q)/6; dot=sum((p[0]-px)*(q[0]-qx)+(p[1]-py)*(q[1]-qy) for p,q in zip(P,Q)); crs=sum((p[0]-px)*(q[1]-qy)-(p[1]-py)*(q[0]-qx) for p,q in zip(P,Q)); th=math.atan2(crs,dot); tx=qx-(math.cos(th)*px-math.sin(th)*py); ty=qy-(math.sin(th)*px+math.cos(th)*py); res=math.sqrt(sum(((math.cos(th)*p[0]-math.sin(th)*p[1]+tx)-q[0])**2+((math.sin(th)*p[0]+math.cos(th)*p[1]+ty)-q[1])**2 for p,q in zip(P,Q))/6); print('theta=%.2f tx=%.3f ty=%.3f rms=%.2e'%(math.degrees(th),tx,ty,res))"

# 变换顺序不同，结果不同：先转再平移 ≠ 先平移再转
python3 -c "import math; a=math.radians(90); c,s=math.cos(a),math.sin(a); x,y=1.0,0.0; r1=(c*x-s*y+2, s*x+c*y+1); r2=(c*(x+2)-s*(y+1), s*(x+2)+c*(y+1)); print('R_then_t=%s t_then_R=%s'%(r1,r2))"
```

预期：往返恢复 `(1,2)`；恢复出 `theta=30.00 tx=1.000 ty=2.000 rms≈4e-16`；两种顺序结果分别为 `(2,2)` 与 `(-1,3)`。

## 4. 动手实验

**目标（40 分钟）**：用合成数据走完一次「标定 → 评价 → 交叉验证」。

1. 用本课命令生成 6 组点对，恢复 R、t；
2. 计算 RMS 与最大残差；
3. 故意把其中 1 个点对平移 1 cm（模拟错配），重新求解，观察 RMS 与参数变化；
4. 留出 2 组点对只做验证，不用来求解，比较训练误差与验证误差；
5. 把二维方法推广思路写清楚：三维用 SVD 求旋转（Kabsch），有外点用 RANSAC；
6. 写结论：几组点对才够？外点影响多大？如何判断标定可信？

**通过判据**：能复现 `theta=30°、t=(1,2)`，并说明加入外点后 RMS 明显上升、验证误差大于训练误差。

> 实机标定时把以上流程换成真实点对，但**真实数据不要写进公开仓库**。

## 5. 自动检查

```bash
python3 -c "import math; P=[(0,0),(1,0),(0,1),(2,1),(1,2),(-1,1)]; a=math.radians(30); c,s=math.cos(a),math.sin(a); Q=[(c*x-s*y+1, s*x+c*y+2) for x,y in P]; px=sum(p[0] for p in P)/6; py=sum(p[1] for p in P)/6; qx=sum(q[0] for q in Q)/6; qy=sum(q[1] for q in Q)/6; dot=sum((p[0]-px)*(q[0]-qx)+(p[1]-py)*(q[1]-qy) for p,q in zip(P,Q)); crs=sum((p[0]-px)*(q[1]-qy)-(p[1]-py)*(q[0]-qx) for p,q in zip(P,Q)); th=math.atan2(crs,dot); tx=qx-(math.cos(th)*px-math.sin(th)*py); ty=qy-(math.sin(th)*px+math.cos(th)*py); res=math.sqrt(sum(((math.cos(th)*p[0]-math.sin(th)*p[1]+tx)-q[0])**2+((math.sin(th)*p[0]+math.cos(th)*p[1]+ty)-q[1])**2 for p,q in zip(P,Q))/6); assert abs(math.degrees(th)-30)<1e-6 and res<1e-9; print('CALIB_OK')"
```

预期输出 `CALIB_OK`。

> 三维工具链的可复现验证（2026-11-06）：在 `ros:noetic-perception` 镜像内用合成数据跑 OpenCV 4.2 的 `solvePnPRansac`（8 个立方体角点、已知内参，恢复旋转/平移误差均 < 0.001° / 1e-6 m）与 `ppf_match_3d_ICP`（400 点、已知刚体变换，残差 1.15e-4、位姿误差 < 0.001）；真实标定板、相机/雷达与手眼运动采集仍未实测。`ppf_match_3d_ICP` 输入用 3 列点云，第 4 列若填齐次 1.0 会被当作法向量导致配准不收敛。

## 6. 常见故障

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 标定后中心准、边缘偏 | 内参/畸变没标或分辨率不匹配 | 重标内参，按实际分辨率用 |
| 重复标定结果差别大 | 姿态太少、数据噪声大 | 增加姿态、剔除外点 |
| 标定残差很小但实操很差 | 激励不足，只覆盖小范围 | 覆盖工作空间并做交叉验证 |
| 动起来误差变大 | 时间不同步，点对错配 | 对齐时间戳，降低运动速度 |
| 旋转对、平移差很多 | 原点定义不一致 | 明确各坐标系原点与单位 |
| 换一个安装位置就全错 | 用了硬编码外参 | 外参配置化并随拆装重标 |
| 标定结果符号相反 | 左手/右手系混用 | 统一右手系，画轴确认 |
