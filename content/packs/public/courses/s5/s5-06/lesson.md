# S5-06 · 20 点触地法与误差判据

> 验证状态：✅ 本课误差统计命令已在本机 Linux 实测（合成数据）；⚠ 未在实车执行 20 点触地法，现场测量方法与判据阈值均为**教学示例**，须按现场 SOP 确认。

## 1. 现场类比

标定报告写着「平均误差 8 mm，合格」。到现场一挖，右边 3 米处总是差 4 cm。

原因很简单：**平均值把超差点平均掉了**。20 个点里 13 个很好、7 个很差，均值依然好看，但挖斗不会按平均值工作。

## 2. 核心概念

### 2.1 什么是触地法

把斗齿依次放到地面上若干**已知位置**，记录当时的关节角/IMU 姿态，用「预测位置 vs 已知位置」的偏差来标定或验收。

| 用途 | 需要什么 |
|---|---|
| 标定 | 足够多、覆盖广的点位，参与参数求解 |
| 验收 | 独立点位，不参与求解，只做检验 |

**同一个点不能既用来拟合又用来验收**，否则等于自己给自己打分。

### 2.2 为什么是 20 个点

- 点太少：只能约束局部，外推不可信；
- 点集中：覆盖不到工作空间边缘，边缘误差发现不了；
- 点分布合理时，20 个点足以暴露系统性偏差（零位、长度、倾斜）。

推荐布点：近/中/远三个距离带 × 左/中/右三个方位，再补少量不同姿态，**不要 20 个点挤在脚边**。

### 2.3 误差指标要看全

| 指标 | 含义 | 为什么重要 |
|---|---|---|
| RMS | 均方根误差 | 反映整体，但会被大误差放大 |
| 最大误差 | 最坏点 | 决定最危险的工况 |
| P95 | 95% 分位 | 比平均值更接近真实体验 |
| 超差点比例 | 超过阈值的点数占比 | 直观衡量「有多少地方不能用」 |
| 分区误差 | 按近/中/远或方位分组 | 定位系统性偏差 |

**报告里必须同时有「整体」和「最坏」**，只报一个都是不完整的。

### 2.4 判据要事先定

- 判据在看数据之前确定，避免「挑数据凑合格」；
- 阈值来自任务需求，不是拍脑袋：作业允许 2 cm，判据就不能定 5 cm；
- 不同区域可以定不同阈值（近处更严）；
- 误差超过判据时，先判断是标定问题还是测量基准问题。

> 本课的阈值（如 RMS 2 cm、最大 5 cm）都是**教学示例值**，不是任何设备的标准。

## 3. 可复制命令 / 代码

```bash
# 20 个触地点的高度误差：RMS 与最大误差
python3 -c "import random,math; random.seed(11); z=[random.gauss(0,0.005) for _ in range(20)]; print('rms=%.4f max=%.4f'%(math.sqrt(sum(v*v for v in z)/20),max(abs(v) for v in z)))"

# 「均值很好看」的假象：1% 倾斜 + 噪声
python3 -c "import random,math; random.seed(11); xs=[random.uniform(-3,3) for _ in range(20)]; z=[0.01*x+random.gauss(0,0.005) for x in xs]; m=sum(z)/20; print('mean_err_cm=%.2f max_err_cm=%.2f within2cm=%d/20'%(abs(m)*100,max(abs(v) for v in z)*100,sum(1 for v in z if abs(v)<=0.02)))"
```

预期：第一组 `rms≈0.005 max≈0.013`；第二组 **平均误差只有 0.26 cm，最大误差 4.54 cm，只有 13/20 个点在 2 cm 以内**。

## 4. 动手实验

**目标（40 分钟）**：对一份 20 点数据做完整误差分析，并给出「合格 / 不合格」结论。

1. 准备 20 个点位的预测值与实测值（实车或合成）；
2. 计算每个点的三维误差或高度误差；
3. 计算 RMS、最大误差、P95、超差点比例（阈值自定并写明理由）；
4. 按近/中/远或左/中/右分组，比较各组 RMS；
5. 判断误差模式：同向偏移 → 零位/长度；随距离增大 → 尺度；随机散布 → 噪声/重复性；
6. 写结论：是否合格？不合格的话，最可能是哪类误差？

**通过判据**：同时给出整体指标与最坏点，并能把误差模式对应到一个可能原因。

## 5. 自动检查

```bash
python3 -c "import random,math; random.seed(11); xs=[random.uniform(-3,3) for _ in range(20)]; z=[0.01*x+random.gauss(0,0.005) for x in xs]; m=sum(z)/20; assert abs(m)<0.01 and max(abs(v) for v in z)>0.02; print('TOUCH_ERROR_OK')"
```

预期输出 `TOUCH_ERROR_OK`：均值小但最大误差大，说明必须看最坏点。

## 6. 常见故障

| 症状 | 可能原因 | 排查 |
|---|---|---|
| 所有点同向偏移 | 零位角/基准高度错 | 检查零位与地面基准 |
| 误差随距离线性增大 | 连杆长度或尺度误差 | 重标长度，检查比例关系 |
| 误差随机散布、不可重复 | 测量方法不稳、结构间隙 | 固定测量流程，检查铰点间隙 |
| 某区域明显更差 | 该姿态下模型简化失效、柔性 | 分区标定或引入柔性补偿 |
| 换一块地结果就变 | 地面基准不平 | 用同一基准面或测量设备校准 |
| 每次标定结果差异大 | 点位太少/太集中、外点多 | 增加覆盖、剔除异常点 |
| 报告合格但现场不行 | 只看了平均误差 | 补看最大误差与分区误差 |
