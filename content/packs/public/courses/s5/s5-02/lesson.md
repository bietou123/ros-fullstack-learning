# S5-02 · LiDAR 驱动与点云

> 验证状态：✅ 本课点云统计命令已在本机 Linux 实测；⚠ 未连接真实 LiDAR 验证驱动与点云，ROS 话题相关命令为标准用法但**本机未实测**。

## 1. 现场类比

挖机挖斗前方有一堵墙，点云里却显示是空的——不是墙没了，是这一帧点云**根本没发出来或时间戳不对**。

点云和图像一样，**“看起来有画面”不代表数据可信**。必须能回答三个问题：这一帧是什么时候采的？在哪个坐标系里？丢了多少点？

## 2. 核心概念

### 2.1 常见类型

| 类型 | 说明 | 典型用途 |
|---|---|---|
| 2D 单线 | 一个平面扫描 | 低成本避障、导航 |
| 3D 机械旋转 | 多线旋转扫描 | 建模、定位 |
| 固态 / MEMS | 无旋转部件，视场固定 | 短距、车载 |
| 面阵 / Flash | 一次成像 | 近距离感知 |

选型时先问：**视场角、量程、角分辨率、扫描周期、防护等级**，而不是只看「多少线」。

### 2.2 PointCloud2 的关键字段

| 字段 | 含义 | 常见坑 |
|---|---|---|
| `x y z` | 点坐标（米） | 单位写成毫米 |
| `intensity` | 反射强度 | 不同厂商定义不同 |
| `ring` | 线号（多线雷达） | 缺失后无法按线过滤 |
| `time` | 单点时间偏移 | 忽略后运动畸变无法校正 |
| `frame_id` | 坐标系名 | 与 TF 树对不上，RViz 里点云飞走 |
| `stamp` | 整帧时间戳 | 用发布时刻而非采样时刻 |

### 2.3 一帧点云要过的四道关

```
原始测距包 ──▶ 驱动解析 ──▶ 坐标变换 ──▶ 下游算法
              │              │
              │              └─ 外参 R,t + frame_id
              └─ 时间戳、ring、去盲区、去无效点
```

驱动的四项义务与 S4-07 一致：**数据转换、时间戳、健康上报、参数校验**。点云还要额外处理无效点（`nan` / `inf`）和盲区噪点。

### 2.4 点云质量怎么判断

| 指标 | 怎么量 | 异常信号 |
|---|---|---|
| 帧率 | `ros2 topic hz` | 低于标称、周期性掉帧 |
| 点数 | 每帧点数是常数 | 突然减半 → 丢包 |
| 最远距离 | 统计半径最大值 | 明显变短 → 遮挡/脏污 |
| 近距噪点 | 半径 < 0.1 m 的点数 | 突然变多 → 镜面/雨雾 |
| 坐标一致性 | 同一墙面两次扫描重合度 | 漂移 → 外参或时间戳 |

## 3. 可复制命令 / 代码

```bash
# 合成 120 个点，按距离分桶（0–5 / 5–10 / 10–15 m）
python3 -c "import math,random; random.seed(7); pts=[(random.uniform(-10,10),random.uniform(-10,10),random.uniform(-1,1)) for _ in range(120)]; r=[math.hypot(x,y) for x,y,z in pts]; b=[sum(1 for v in r if lo<=v<hi) for lo,hi in ((0,5),(5,10),(10,15))]; print('buckets=%s total=%d'%(b,sum(b)))"

# 按半径过滤近距噪点（<0.5 m 丢弃）
python3 -c "import math,random; random.seed(7); pts=[(random.uniform(-10,10),random.uniform(-10,10)) for _ in range(120)]; keep=[p for p in pts if math.hypot(*p)>=0.5]; print('kept=%d dropped=%d'%(len(keep),len(pts)-len(keep)))"
```

预期：`buckets=[18, 74, 28] total=120`，说明点数守恒；过滤前后总数能对上。

## 4. 动手实验

**目标（35 分钟）**：建立一份「点云健康检查」清单，并用合成数据跑通统计。

1. 准备一份点云（实机导出的 PCD，或本课合成数据）；
2. 统计：总点数、半径最小值/最大值/均值、按距离分桶的分布；
3. 统计无效点数量（`nan` / `inf`）与近距噪点数量（半径 < 0.1 m）；
4. 用两次相邻扫描对比同一区域，粗略估计重合度；
5. 写一张表：帧率、点数、量程、近距噪点率、`frame_id`、时间戳来源；
6. 给出结论：这份点云能否直接给下游算法用？还需要哪些处理？

**通过判据**：点数守恒（分桶之和 = 总点数），并能指出至少一项可能的数据质量风险。

## 5. 自动检查

```bash
python3 -c "import math,random; random.seed(7); pts=[(random.uniform(-10,10),random.uniform(-10,10),random.uniform(-1,1)) for _ in range(120)]; r=[math.hypot(x,y) for x,y,z in pts]; b=[sum(1 for v in r if lo<=v<hi) for lo,hi in ((0,5),(5,10),(10,15))]; assert sum(b)==120 and min(r)>=0; print('PCD_STATS_OK')"
```

预期输出 `PCD_STATS_OK`。

## 6. 常见故障

| 症状 | 可能原因 | 排查 |
|---|---|---|
| 点云全为空 / 全零 | 驱动未发布、话题名错、时间戳为 0 | 看 `topic hz`、`frame_id`、驱动日志 |
| 点数周期性减半 | 网络丢包、带宽不足 | 查网口速率与丢包计数 |
| RViz 中点云位置整体偏移 | 外参与实际安装不符 | 重新标定，见 S5-04 |
| 点云在 RViz 中「飞走」 | `frame_id` 不在 TF 树里 | `ros2 run tf2_tools view_frames` |
| 近处一片噪点 | 镜面反射、雨雾、脏污 | 清洗镜头，加距离滤波 |
| 运动时墙面出现「重影」 | 未做运动畸变校正 / 时间戳不准 | 用 `time` 字段与 IMU 补偿 |
| 下游报坐标系不存在 | 驱动与算法约定不一致 | 统一 frame 命名与坐标轴方向 |
