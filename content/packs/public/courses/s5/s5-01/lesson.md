# S5-01 · IMU 原理、噪声与安装方向

> 验证状态：✅ 本课噪声统计命令已在本机 Linux 实测；⚠ IMU 实机静止数据采集未实测（无硬件），文中用合成数据代替，结论同样成立。

## 1. 现场类比

设备静止停在平地上，姿态显示却在 10 分钟内慢慢「低头」了 3 度。

这不是算法坏了，是 IMU 在正常工作：陀螺仪测的是角速度，**角速度积分一次就变成角度，而零偏也会被一起积分**。时间越长，漂得越多。

更隐蔽的是安装方向：丝印箭头朝上，不等于它装成了你要的坐标系。轴装反了，车往前，姿态却说往后，**上层算法越「聪明」，错得越离谱**。

## 2. 核心概念

### 2.1 IMU 测什么

| 器件 | 物理量 | 单位 | 主要误差 |
|---|---|---|---|
| 陀螺仪 gyroscope | 角速度 | °/s 或 rad/s | 零偏 bias、随机游走、温度漂移 |
| 加速度计 accelerometer | 比力（含重力） | m/s² 或 g | 振动、安装倾斜、零偏 |
| 磁力计 magnetometer（9 轴才有） | 磁场方向 | µT | 电机/金属干扰，现场基本不可信 |

**6 轴 = 陀螺 + 加速度；9 轴再加磁力计。** 工业现场有大量电机和钢结构，磁力计的「航向」经常不可用，不要默认它可信。

### 2.2 姿态是怎么来的

```
陀螺角速度 ──积分──▶ 短时准、长时漂
加速度重力方向 ──▶ 长时准、短时被振动带偏
                └── 互补滤波 / Mahony / EKF ──▶ 姿态
```

一句话：**用加速度计纠正陀螺的长期漂移，用陀螺抑制加速度计的短期噪声。** 没有任何一个单独就够用。

### 2.3 噪声指标怎么看

| 指标 | 含义 | 用途 |
|---|---|---|
| 零偏 bias | 静止时输出的非零均值 | 补偿后漂移显著变小 |
| 噪声密度 | 每 √Hz 的噪声水平 | 对比不同器件 |
| 零偏不稳定性 | 零偏随时间缓慢变化的幅度 | Allan 方差曲线底部 |
| 随机游走 | 积分后误差增长速率 | 判断多久必须重标定 |

**不要只看「精度 ±0.1°」这种宣传语**，要看静止噪声和零偏稳定性，那才决定实际能不能用。

### 2.4 安装方向（外参 R）

IMU 输出的是**传感器坐标系**下的量，算法要的是**车体/臂体坐标系**下的量，两者差一个旋转矩阵 `R_sensor_to_body`。

常见 6 种正交安装姿态：绕每个轴 0°/90°/180°/270°。标定前必须确认：

1. 右手系；
2. 三个轴的正方向分别对应车体的哪个方向；
3. 安装面是否水平（倾角误差会直接混进加速度计的重力分量）；
4. 螺丝是否拧紧（振动会让 IMU 相对本体微动，噪声看起来忽大忽小）。

> 安装误差本身就是外参的一部分。**不要用「装得正」代替标定。**

## 3. 可复制命令 / 代码

```bash
# 合成一段静止数据：均值 0，标准差 0.02（单位按角速度理解）
python3 -c "import random,statistics; random.seed(42); xs=[random.gauss(0,0.02) for _ in range(2000)]; print('mean=%.5f'%statistics.mean(xs)); print('std=%.5f'%statistics.stdev(xs))"

# 10 点平均后，白噪声应降到约 1/sqrt(10)
python3 -c "import random,statistics; random.seed(42); xs=[random.gauss(0,0.02) for _ in range(2000)]; ys=[sum(xs[i:i+10])/10 for i in range(0,2000,10)]; print('raw_std=%.5f avg10_std=%.5f'%(statistics.stdev(xs),statistics.stdev(ys)))"

# 传感器坐标 -> 本体坐标：绕 z 轴旋转 90°
python3 -c "import math; c,s=0.0,1.0; x,y,z=1.0,0.0,0.0; print('body=(%.3f,%.3f,%.3f)'%(c*x-s*y, s*x+c*y, z))"
```

预期：`std≈0.020`；`avg10_std≈0.0068`（约 1/√10）；旋转后 `body=(0.000,1.000,0.000)`。

## 4. 动手实验

**目标（35 分钟）**：完成一次「静止噪声测试」，并判断这只 IMU 能不能用于你的控制环。

1. 把设备静止放在水平、无振动的台面上，预热 5 分钟（温度稳定后零偏才稳定）；
2. 以固定频率采集 ≥2000 个样本（陀螺三轴 + 加速度三轴都要）；
3. 计算每轴的均值（零偏）、标准差（噪声）、峰峰值（异常跳变）；
4. 每 10 点做滑动平均，比较平均前后的标准差，验证是否接近 1/√10；
5. 记录安装方向：画一张表，写清 sensor x/y/z 分别指向车体的哪个方向；
6. 写结论：零偏多大、噪声多大、是否需要在线零偏补偿、多久重标定一次。

没有实机时，用本课合成数据走完流程即可，**但要明确标注这是合成数据，不能当作器件指标。**

**通过判据**：能给出三轴零偏、三轴噪声、平均前后的对比，以及一张安装方向表。

## 5. 自动检查

```bash
python3 -c "import random,statistics; random.seed(42); xs=[random.gauss(0,0.02) for _ in range(2000)]; ys=[sum(xs[i:i+10])/10 for i in range(0,2000,10)]; assert abs(statistics.stdev(xs)-0.02)<0.002 and statistics.stdev(ys)<statistics.stdev(xs)/2; print('IMU_STATS_OK')"
```

预期输出 `IMU_STATS_OK`：噪声与平均降噪都符合理论。

## 6. 常见故障

| 症状 | 可能原因 | 排查 |
|---|---|---|
| 静止姿态缓慢漂移 | 零偏未补偿 / 温度未稳定 | 看静止 10 分钟均值与温度 |
| 设备前进、姿态显示后退 | 安装轴反向或坐标系不匹配 | 核对 sensor→body 的 R，做单轴转动测试 |
| 振动时加速度计数值大幅波动 | 安装松动 / 未做低通 | 拧紧螺丝，检查滤波截止频率 |
| 磁力计航向乱跳 | 电机磁场干扰 | 现场不要依赖磁力计定航向 |
| 两套数据时间对不齐 | 时间戳用了处理时刻 | 在驱动/硬件层打戳，见 S4-07 |
| 换一台设备表现差很多 | 器件等级不同、零偏不同 | 每台单独测零偏，不能共用参数 |
