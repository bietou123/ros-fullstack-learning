# S9-03 · 激光 / IMU 配置与调参

> 验证状态：✅ 本机 Linux 实测了采样率与混叠频率计算；⚠ 具体传感器型号、量程与参数值未在实机验证，配置项以设备手册为准。

## 1. 现场类比

点云看起来在抖，IMU 数值发飘。有人把滤波越调越重，抖动是小了，可机器反应也变慢了——**新问题换掉了旧问题。**

调参不是「把曲线弄平滑」，是在噪声、延迟、信息量之间做取舍。

## 2. 核心概念

### 2.1 采样率决定你能看到什么

奈奎斯特：采样率 `fs` 能无失真表示的最高频率是 `fs/2`。

| 采样率 | 可分辨上限 | 说明 |
|---:|---:|---|
| 100 Hz | 50 Hz | 低于常见机械振动频段 |
| 200 Hz | 100 Hz | 常见 IMU 默认档 |
| 400 Hz | 200 Hz | 高动态场景 |

**超过上限的频率不会消失，只会伪装成低频。**

### 2.2 混叠：采不到，还会骗你

```
alias = |round(f / fs) × fs − f|
```

例：120 Hz 的振动，用 200 Hz 采样，`round(120/200)=1`，混叠到 `|200−120| = 80 Hz`。你在频谱上看到 80 Hz，会误以为是另一个振动源。

**混叠一旦发生，软件滤波救不回来**——只能在采样前做抗混叠滤波，或提高采样率。

### 2.3 滤波的代价是延迟

一阶低通：

```
y[k] = α·x[k] + (1−α)·y[k−1]
```

- α 越小，越平滑，延迟越大；
- 控制回路里的滤波延迟会直接叠加到 S9-01 的总时延上。

**滤波参数要按「允许多少延迟」反推，而不是按「看起来多平滑」拍。**

### 2.4 激光配置要点

| 项 | 关注点 |
|---|---|
| 扫描频率 | 与运动速度匹配，太快会稀、太慢会拖影 |
| 角分辨率 | 决定远处点间距 |
| 量程 / 盲区 | 近处目标可能直接丢失 |
| 回波模式 | 强反射、雨雾场景的取舍 |
| 时间戳 / frame_id | 与 TF 一致，否则点云「漂」 |
| 过滤 | 角度裁剪、距离裁剪、降采样 |

### 2.5 IMU 配置要点

| 项 | 关注点 |
|---|---|
| 量程 | 加速度 g、角速度 dps；量程越大分辨率越低 |
| 采样率 / 带宽 | 与振动频段匹配，注意混叠 |
| 内参 | bias、噪声密度（S5-01） |
| 安装方向 | 坐标系与机体一致（S5-07） |

### 2.6 调参的基本纪律

1. 先确认硬件、安装、时间戳没问题，再动参数；
2. 每次只改一个参数；
3. 改前改后都留存原始数据；
4. 用同一段数据对比，不用「感觉更顺了」当结论；
5. 参数写进配置模板，标注单位和适用范围。

## 3. 可复制命令 / 代码

```bash
# 采样率与混叠：200 Hz 采样遇到 120 Hz 振动
python3 -c "fs=200.0; fv=120.0; alias=abs(round(fv/fs)*fs-fv); print('imu_hz=%d lidar_hz=%d alias_hz=%d'%(fs,10,alias))"
```

预期：

```
imu_hz=200 lidar_hz=10 alias_hz=80
```

含义：200 Hz 采样下，120 Hz 振动会以 80 Hz 的假频率出现。

## 4. 动手实验

**目标（35 分钟）**：理解采样、滤波、混叠三者的取舍，产出配置模板。

1. 静止采集 60 s IMU 数据，计算均值和标准差；
2. 用 α=0.1 / 0.3 / 0.6 分别滤波，比较平滑程度与阶跃响应延迟；
3. 计算你设备采样率下能分辨的最高频率；
4. 用第 3 节代码算一个关心的振动频率是否混叠；
5. 写配置模板：采样率、量程、滤波参数、坐标约定，全部标单位；
6. 写结论：哪个参数对效果影响最大？代价是什么？

**通过判据**：能解释混叠现象；滤波参数有延迟评估；配置模板可直接复用且无设备标识信息。

## 5. 自动检查

```bash
python3 -c "fs=200.0; fv=120.0; alias=abs(round(fv/fs)*fs-fv); assert alias==80; print('TUNING_OK')"
```

预期输出 `TUNING_OK`。

## 6. 常见故障

| 症状 | 可能原因 | 排查 |
|---|---|---|
| 频谱出现莫名低频峰 | 混叠 | 算 alias，提高采样率或加抗混叠滤波 |
| 点云抖动 | 安装松动 / 时间戳错位 | 查固定与 TF，不是先加滤波 |
| 点云拖影 | 扫描频率与运动不匹配 | 提高扫描频率或降低速度 |
| IMU 数值漂移 | bias 未标定 / 温漂 | 重新标定，检查温度 |
| 滤波后响应变慢 | α 过小 | 按延迟预算调整 |
| 近处目标消失 | 进入盲区 | 调整安装位置或量程 |
| 换传感器后全部参数失效 | 量程/坐标系不同 | 重新核对配置模板 |
